# 🧸 童趣游戏屋

为 **3~6 岁**儿童设计的网页小游戏合集，**575 个寓教于乐的小游戏**，每个都有独特玩法与巧思，有设计感、能反复玩。

零第三方游戏引擎，纯 **Vite + TypeScript + 原生 Canvas/DOM/SVG**，构建后是可双击打开的静态站点，手机 / 平板 / 电脑通吃。

## 📈 难度自适应系统

每个游戏 3 档难度（`easy` / `medium` / `hard`），由 `src/core/adaptive.ts` 的纯函数驱动，**真正闭环**（不是只读历史最高档）：

| 信号                              | 动作       |
| --------------------------------- | ---------- |
| 连续 2 局在当前档拿 **3★ + 通关** | 升一档     |
| 连续 2 局 **未通关 / 1★**         | 降一档     |
| 其他情况                          | 保持当前档 |

**起始难度优先级**：家长锁定 ＞ 自适应建议（含「太难/玩不通」反馈降档信号）＞ 历史最高通关档 ＞ `easy`。

- 家长可在面板锁定难度（自动 / 简单 / 中等 / 困难），锁定时自适应让位。
- 孩子点「太难」反馈会累积 `hardFeedbackCount`，下次自动温柔降一档（但不强制）。
- 算法保守（2 局窗口），避免难度频繁抖动挫败感。

## 👨‍👩‍👧 家长报告系统

家长面板（右上角 ⚙️）展示 `buildParentReport(save)` 计算的能力概览：

| 指标           | 说明                                 |
| -------------- | ------------------------------------ |
| 体验 / 通关数  | 已打开 / 已通关的游戏数（共 575）    |
| 完成率         | 通关数 ÷ 575                         |
| 累计时长       | 所有局的有效游玩时长合计（分钟）     |
| 平均单局时长   | 累计时长 ÷ 总局数（观察专注节奏）    |
| 平均星数       | 已体验游戏的平均最高星               |
| 优势能力 Top 3 | 按平均星 + 通关数排序的能力域        |
| 建议练习 Top 3 | 体验过但未全通关、星数偏低的能力域   |
| 推荐下一步     | 5 个游戏：优先未玩过的，其次未通关的 |

能力域按 `tag` 的「·」前缀聚合（认知 / 反应 / 数学 / 科学 / 语言 / 逻辑 / 记忆 / 艺术 / 生活 / 创造 / 社交 / 精细 / 专注 / 健康 …）。

家长面板还包含：

- **🧠 六大领域能力**（加德纳多元智能）：感知认知 / 语言文字 / 数理逻辑 / 身体动觉 / 艺术创造 / 社会情感，每领域显示体验数、通关数、平均星数、通关率。
- **📚 学习路径进度**：5 条路径各显示 N/M 通关 + 百分比 + ✅ 完成。
- **🔊 任务朗读开关**：为不识字的孩子开启语音朗读（浏览器原生 TTS，离线可用）。
- **☁️ 反馈同步开关**：将孩子/家长提交的问题反馈实时推送到 generic-admin 后台统一管理（默认关闭 opt-in）。

## 💡 贯穿全局的设计巧思

### 1. 统一世界观

一个**大厅**入口，575 个游戏是"房间"，有吉祥物 **"点点"**（圆滚滚的彩色小精灵）全程陪伴、引导、庆祝。

大厅支持按游戏名、能力域、年龄、预计时长和通关状态组合筛选，便于家长快速找到适合当前练习目标的内容。

### 2. 永不"失败"（儿童心理学）

- 答错**不给红叉**，而是温柔鼓励（"再想想看～"）+ 吉祥物眨眼。
- **休息护盾**：连续答错 3 次自动弹出"休息一下"提示，避免挫败。

### 3. 多感官正向反馈

正确时有 ✨ **粒子特效** + 叮咚音效 + 吉祥物跳舞；通关有**满屏彩纸**。

### 4. 家长面板（右上角 ⚙️）

- 音效开关、休息护盾开关、难度锁定（自动 / 简单 / 中等 / 困难）
- **家长报告**：体验数、通关数、完成率、累计时长、优势能力、建议练习、推荐下一步
- **成就墙** + 各游戏进度（星数、通关标记）
- 一键重置进度

### 5. 内容发现与筛选

575 个游戏按**能力域**（认知 / 反应 / 数学 / 科学 / 语言 / 逻辑 / 记忆 / 艺术 / 生活 / 创造 / 社交 / 精细 / 专注 / 健康）、**年龄**（3-4 / 3-5 / 3-6 / 4-5 / 4-6 / 5-6）、**预计时长**、**通关状态**组合筛选，并支持按游戏名搜索——方便家长在庞大的内容库里快速定位适合当前练习目标的游戏。

### 6. PWA 离线安装（可装到桌面/主屏幕）

`manifest.webmanifest`（standalone 模式，主题色 `#ffd166`）+ `sw.js`（v5，stale-while-revalidate）让本站可像原生 App 一样安装，适合平板与家庭场景离线使用。

**安装方法：**

- **桌面 Chrome / Edge**：地址栏右侧点「安装」图标，或菜单 → 「安装 童趣游戏屋…」。
- **Android Chrome**：菜单 → 「添加到主屏幕」/「安装应用」。
- **iOS Safari**：分享 → 「添加到主屏幕」（以独立全屏方式打开）。
- **Windows**：安装后从开始菜单启动，自动全屏无地址栏。

安装后：

- 离线可继续游玩已缓存的游戏，进度存 `localStorage` 不丢。
- Service Worker 采用 stale-while-revalidate：优先秒开缓存，后台静默更新。
- 每局结算累计有效游玩时长，家长报告展示总时长与平均单局时长。

### 7. 自适应难度 + 成就系统

难度根据孩子历史表现自动升档；通关获得星数与成就，进度 **localStorage 持久化**，下次继续。集齐全部 575 个游戏通关解锁**隐藏成就**。

## 🛠 技术栈与工程

- **Vite 5 + TypeScript 5.9**（严格模式，`noUncheckedIndexedAccess` 全开）
- **零运行时依赖**：无 Phaser / Pixi 等游戏引擎，全部原生实现
- **音效零文件**：用 Web Audio API 程序合成（正弦/三角波 + ADSR 包络），体积为 0
- **视觉零图片**：所有角色 / 场景用纯 CSS + SVG 绘制，加载快、可主题切换、矢量不糊
- **懒加载**：每个游戏是独立 chunk，首屏只加载大厅，按需加载
- **内容发现**：大厅筛选逻辑集中在 `src/lobby/contentFilters.ts`，覆盖能力域、年龄、预计时长、通关状态和搜索
- **触屏 + 桌面并重**：统一 PointerEvent 抽象，触控区 ≥ 64px，响应式布局

### 质量保障

```bash
npm run type-check   # TypeScript 类型检查
npm run lint         # ESLint
npm test             # 124 项单元测试（核心算法 / 存档 / 成就 / 反馈 / 自适应 / 家长报告 / 大厅筛选 / PWA / registry 一致性）
```

## 🎯 设计哲学

> 致敬"大善"精神：无论孩子做得怎样，都被温柔托住。强调**努力**而非天赋，用**具体**而非空泛的夸赞，让 3-6 岁的孩子在每一次点击中都感受到被肯定。

本工程与同工作区的 `dashan`（大善系统）项目同构（Vite + TS），独立部署、互不干扰。
